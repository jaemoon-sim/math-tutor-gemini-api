# 현재 학생 진도

- 학년: 고등학교 3학년
- 계열/성향: 자연계열, 수능 수학 미적분 선택 수준
- 현재 단원: 미적분Ⅱ와 기하 주요 내용을 학습 완료
- 목표:
  - 고등학교 교육과정 안에서 문제를 정확히 풀기
  - 풀이 과정에서 어떤 단원 개념을 썼는지 확인하기
  - 계산 실수와 조건 해석 실수를 줄이기

  - 벡터미적분

  - 문제에서 명시되지 않은 물리 공식이나 공학 공식을 임의로 사용하지 않는다.

## 풀이 선호

- 고등학교 교육과정 안의 풀이를 우선한다.
- 같은 문제를 여러 방법으로 풀 수 있으면, 먼저 가장 표준적인 풀이를 제시한다.
- 필요하면 보조 풀이로 그래프 해석, 미분 활용, 벡터 활용을 제시할 수 있다.
- 풀이에 사용한 과목과 단원을 명확히 표시한다.
- 계산이 긴 문제에서는 중간 계산을 생략하지 말고 실수하기 쉬운 지점을 짚어준다.
- 답만 제시하지 말고 조건 해석, 풀이 전략, 계산, 검산 순서로 설명한다.
- 교육과정 밖 개념을 쓰면 반드시 `교육과정 밖 참고`라고 표시하고, 기본 풀이와 분리한다.

## 추천/오답노트 기록 기준

- 풀이 후 다음 항목을 반드시 남긴다.
  - 문제 단원
  - 사용한 과목
  - 사용한 핵심 개념
  - 실수 가능성이 높은 단계
  - 부족한 선수 개념
  - 추천 복습 단원
- 같은 유형을 반복해서 틀리면 단순 계산 실수인지, 개념 연결 부족인지 구분한다.
