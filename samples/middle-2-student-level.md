# 현재 학생 진도

- 학년: 중학교 2학년
- 현재 단원: 피타고라스 정리까지 완료
- 이미 배운 내용:
  - 중1 소인수분해
  - 중1 정수와 유리수
  - 중1 문자의 사용과 식
  - 중1 일차방정식
  - 중1 좌표평면과 그래프
  - 중1 기본 도형
  - 중1 작도와 합동
  - 중1 평면도형의 성질
  - 중1 입체도형의 성질
  - 중1 대푯값
  - 중1 도수분포표와 상대도수
  - 중2 유리수와 순환소수
  - 중2 식의 계산
  - 중2 일차부등식
  - 중2 연립일차방정식
  - 중2 일차함수
  - 중2 일차함수와 일차방정식의 관계
  - 중2 삼각형과 사각형의 성질
  - 중2 도형의 닮음
  - 중2 피타고라스 정리
- 아직 배우지 않은 내용:
  - 경우의 수와 확률
  - 제곱근과 실수
  - 다항식의 곱셈과 인수분해
  - 이차방정식
  - 이차함수
  - 삼각비
  - 원의 성질
  - 산포도
  - 상자 그림과 산점도
- 설명 선호:
  - 문제에 필요한 중2 이하 개념을 먼저 사용한다.
  - 피타고라스 정리, 닮음, 일차함수까지는 사용해도 된다.
  - 제곱근, 이차방정식, 삼각비는 아직 배우지 않은 개념으로 보고 사용하지 않는다.
  - 계산 실수 포인트를 짚어준다.
  - 고등학교식 빠른 풀이보다 중학교 2학년 풀이를 우선한다.
