# 2022 개정 교육과정 - 고등학교 수학 정리

> 목적: 수학 문제 풀이 서비스에서 고등학교 학생의 현재 이수 과목과 진도에 맞춰 풀이 수준을 조절하기 위한 교육과정 지식 베이스 초안.
>
> 기준: 2022 개정 교육과정 고등학교 수학과. 나무위키/나무모에의 고등학교 수학과 문서와 과목별 문서를 시작점으로 삼고, NCIC 국가교육과정정보센터의 2022 개정 교육과정 고시 정보를 함께 확인했다.
>
> 주의: 고교학점제에서는 학교와 학생 선택에 따라 이수 순서가 달라질 수 있다. 이 파일은 문제 풀이용 맥락을 만들기 위한 과목 지도이며, 실제 학생 프로필에는 `이수 과목`, `현재 단원`, `아직 배우지 않은 과목`을 명시해야 한다.

## 전체 과목 체계

| 구분 | 과목 | 풀이 서비스에서의 기본 역할 |
|---|---|---|
| 공통 과목 | 공통수학1, 공통수학2 | 대부분의 고등학생이 먼저 배우는 고등 수학 기초. 고1 수준 풀이의 기본 기준 |
| 공통 과목 | 기본수학1, 기본수학2 | 공통수학의 기초/대체 성격. 특성화고 또는 기초 보완 맥락에서 사용 |
| 일반 선택 | 대수 | 지수로그, 삼각함수, 수열. 수능/일반계열 선택 이후 풀이의 핵심 |
| 일반 선택 | 미적분Ⅰ | 함수의 극한과 연속, 다항함수 미분/적분의 기초 |
| 일반 선택 | 확률과 통계 | 경우의 수 심화, 확률, 확률분포와 통계적 추정 |
| 진로 선택 | 미적분Ⅱ | 수열의 극한, 여러 함수의 미분법과 적분법 |
| 진로 선택 | 기하 | 이차곡선, 공간도형과 공간좌표, 벡터 |
| 진로 선택 | 경제 수학 | 경제/금융 맥락의 수, 함수, 행렬, 미분 활용 |
| 진로 선택 | 인공지능 수학 | 데이터, 텍스트/이미지 처리, 예측/최적화와 수학 연결 |
| 진로 선택 | 직무 수학 | 직무 상황에서 필요한 수와 연산, 비율, 도형, 자료 해석 |
| 융합 선택 | 수학과 문화 | 수학의 역사, 예술, 사회, 기술 문화와의 연결 |
| 융합 선택 | 실용 통계 | 실제 자료 수집, 분석, 시각화, 통계적 의사결정 |
| 융합 선택 | 수학과제 탐구 | 수학 탐구 주제 설정, 자료 수집, 탐구 수행과 발표 |
| 과학 계열 선택 | 전문 수학, 이산 수학, 고급 대수, 고급 미적분, 고급 기하 | 일반계열 풀이 기본 범위 밖. 학생이 명시적으로 이수한 경우에만 사용 |

## LLM 풀이 공통 규칙

- 학생의 현재 이수 과목과 현재 단원을 먼저 확인한다.
- `공통수학`을 배운 학생에게도 `대수`, `미적분Ⅰ`, `확률과 통계` 개념을 자동으로 사용하지 않는다.
- 선택 과목은 학생 프로필에 명시된 경우에만 허용한다.
- 같은 문제라도 풀이 도구를 학생 수준에 맞춘다. 예: 이차함수 문제는 공통수학 수준에서는 판별식/그래프/완전제곱식 중심, 미적분 이수 후에는 미분을 보조 도구로 쓸 수 있다.
- 고등학교 문제 풀이 결과에는 `사용한 과목`, `사용한 단원`, `필요 선수 개념`, `다음 복습 단원`, `고급 풀이 사용 여부`를 구조화해 남긴다.
- 계산이 복잡한 문제에서는 공학 도구 사용 가능성을 언급할 수 있지만, 기본 풀이의 논리는 교육과정 개념으로 설명한다.

## 이수 흐름 가이드

```text
중학교 수학
  -> 공통수학1
  -> 공통수학2
  -> 일반 선택: 대수, 미적분Ⅰ, 확률과 통계
  -> 진로 선택: 미적분Ⅱ, 기하, 경제 수학, 인공지능 수학, 직무 수학
  -> 융합 선택: 수학과 문화, 실용 통계, 수학과제 탐구
```

- 공통수학1, 공통수학2는 고등학교 수학 풀이의 기본 베이스다.
- 기본수학1, 기본수학2는 공통수학과 같은 큰 틀을 공유하되, 계산과 활용을 더 기초적이고 간단한 수준으로 다룬다.
- 대수, 미적분Ⅰ, 확률과 통계는 일반 선택이며 2028학년도 이후 수능 수학 출제 범위로 언급되는 핵심 과목군이다.
- 미적분Ⅱ와 기하는 자연계/공학계 심화 문제 풀이에서 자주 필요하지만, 모든 학생에게 기본 허용 개념으로 두면 안 된다.

  - 경제 수학 최적화
- 설명 제한:
  - 매개변수 함수와 음함수는 간단한 것만 다룬다.
  - 미분방정식과 고계도함수 일반론은 사용하지 않는다.

#### 3. 적분법

- 성취기준: `[12미적Ⅱ-03-01]` ~ `[12미적Ⅱ-03-07]`
- 핵심 목표:
  - 실수 지수 거듭제곱함수, 지수함수, 삼각함수의 적분을 계산한다.
  - 치환적분법과 부분적분법을 활용한다.
  - 정적분과 급수의 합 사이 관계를 이해한다.
  - 넓이, 부피, 속도와 거리 문제에 적분을 활용한다.
- 핵심 개념:
  - 여러 함수의 부정적분과 정적분
  - 치환적분법
  - 부분적분법
  - 정적분과 급수
  - 입체도형의 부피
- 허용 풀이 도구:
  - 기본 적분 공식
  - 치환적분
  - 부분적분
  - 정적분 활용
  - 넓이와 부피 계산
- 선수 개념:
  - 미적분Ⅰ 적분
  - 미적분Ⅱ 미분법
- 설명 제한:
  - 회전체의 부피는 기본 범위로 두지 않는다.
  - 적분법 활용에서 지나치게 복잡한 문제는 피한다.

### 경제 수학

- 과목 성격:
  - 경제 및 금융 상황을 수학적으로 해석하고 합리적 의사결정을 돕는 진로 선택 과목.
- 단원:
  - 수와 경제: 비율, 백분율, 지수, 지표, 환율, 세금, 이자 등 경제량의 수치 표현
  - 함수와 경제: 수요와 공급, 비용, 수입, 이윤, 균형점 등 함수 모델
  - 행렬과 경제: 투입산출표나 자료 배열을 행렬로 표현하고 계산
  - 미분과 경제: 한계비용, 한계수입, 최적화
- 허용 풀이 도구:
  - 비율과 백분율 계산
  - 등비적 증가와 이자 계산
  - 일차함수/이차함수/지수함수 기반 경제 모델
  - 행렬을 이용한 자료 정리
  - 미분을 이용한 최댓값/최솟값 판단
- 선수 개념:
  - 공통수학1, 공통수학2
  - 대수 지수로그함수
  - 미적분Ⅰ 미분
- 설명 제한:
  - 실제 금융상품 수준의 복잡한 세법, 회계, 최적화 이론은 다루지 않는다.

### 인공지능 수학

- 과목 성격:
  - 인공지능에서 데이터 처리와 의사결정에 쓰이는 수학을 탐구하는 진로 선택 과목.
- 단원:
  - 인공지능과 빅데이터
  - 텍스트 데이터 처리
  - 이미지 데이터 처리
  - 예측과 최적화
  - 인공지능과 수학 탐구
- 핵심 개념:
  - 데이터, 벡터, 행렬
  - 텍스트의 수치화
  - 이미지의 픽셀 표현
  - 유사도, 분류, 예측
  - 최적화와 손실 개념
- 허용 풀이 도구:
  - 자료를 벡터나 행렬로 표현하기
  - 빈도와 비율 계산
  - 간단한 거리/유사도 비교
  - 그래프나 표로 데이터 경향 해석
- 선수 개념:
  - 공통수학1 행렬
  - 공통수학2 함수와 그래프
  - 확률과 통계 기초
- 설명 제한:
  - 미분 기반 딥러닝 학습 알고리즘, 선형대수 일반론, 확률모형 일반론은 학생이 별도 이수하지 않았다면 쓰지 않는다.

### 직무 수학

- 과목 성격:
  - 직무 상황에서 필요한 수학 개념을 활용해 문제 해결과 의사결정을 돕는 진로 선택 과목.
- 단원:
  - 수와 연산: 수 개념, 사칙연산, 어림, 단위 환산
  - 변화와 관계: 비, 비율, 백분율, 표와 그래프, 일차방정식/일차부등식
  - 도형과 측정: 겨냥도, 전개도, 도형의 이동/합동/닮음, 둘레/넓이/부피
  - 자료와 가능성: 경우의 수, 가능성, 표와 그래프 정리/해석
- 허용 풀이 도구:
  - 비용, 예산, 수익 계산
  - 환율, 단가, 할인율, 손익률 계산
  - 요율표와 그래프 해석
  - 설계도, 배치도, 전개도 해석
  - 자료를 표/그래프로 정리하고 의사결정하기
- 선수 개념:
  - 중학교 수학 전반
  - 기본수학 또는 공통수학 일부
- 설명 제한:
  - 이론 전개보다 실제 상황 적용을 우선한다.

## 융합 선택 과목

### 수학과 문화

- 과목 성격:
  - 수학을 역사, 예술, 건축, 음악, 사회, 기술 등 문화적 맥락과 연결해 탐구하는 과목.
- 활용 맥락:
  - 수학 개념의 역사적 배경 설명
  - 도형, 비례, 대칭, 패턴의 문화적 사례
  - 수학적 아이디어가 사회와 기술에 미친 영향
- 풀이 서비스 역할:
  - 계산 문제의 직접 풀이보다는 개념 배경 설명, 흥미 유발, 탐구 주제 추천에 사용한다.

### 실용 통계

- 과목 성격:
  - 실제 자료를 수집, 정리, 분석, 시각화하고 통계적으로 의사결정하는 융합 선택 과목.
- 활용 맥락:
  - 설문 자료 분석
  - 표본 자료와 시각화
  - 공학 도구를 이용한 데이터 처리
  - 통계 결과 해석과 비판
- 선수 개념:
  - 중학교 자료와 가능성
  - 확률과 통계 또는 이에 준하는 기본 통계 개념
- 풀이 서비스 역할:
  - 통계 프로젝트, 자료 해석, 그래프 비판, 보고서형 문제에 사용한다.

### 수학과제 탐구

- 과목 성격:
  - 학생이 수학 탐구 주제를 정하고, 자료를 수집하며, 탐구 과정을 정리해 발표하는 과목.
- 활용 맥락:
  - 탐구 주제 구체화
  - 가설과 질문 만들기
  - 자료 수집 계획
  - 수학적 모델링
  - 탐구 결과 보고서 구성
- 풀이 서비스 역할:
  - 단일 문제 풀이보다 프로젝트 코칭, 주제 추천, 탐구 설계 피드백에 사용한다.

  - 지수로그함수, 삼각함수, 수열

  - 확률분포, 통계적 추정

  - 수열과 수학적 귀납법

  - 확률분포, 이항분포, 정규분포
  - 통계적 추정
- 주의:
  - 원순열이나 고급 조합론은 일반계열 기본 범위로 두지 않는다.

### 미적분Ⅱ/기하 이수 수준

- 미적분Ⅱ:
  - 수열의 극한, 급수
  - 여러 함수의 미분법
  - 치환적분, 부분적분, 정적분 활용

  - 이차곡선
  - 공간도형과 공간좌표
  - 벡터
- 주의:
  - 대학 수준의 해석학, 선형대수, 미분방정식, 벡터미적분은 기본 사용하지 않는다.
